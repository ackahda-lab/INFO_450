INFO 450: Data Structures and Systems Analysis
Virginia Commonwealth University (VCU) | School of Business

Department of Information Systems

Course Overview
INFO 450 focuses on the design, analysis, and implementation of complex information systems and data structures. This course bridges the gap between software development and systems engineering, emphasizing structured logic, algorithm efficiency, and object-oriented design principles to solve modern business problems.

Key Learning Objectives
Data Structure Implementation: Design and manipulate essential structures including arrays, linked lists, stacks, queues, trees, and hash tables.

Systems Analysis & Design: Map business requirements into functional software architectures using modern modeling tools and methodologies.

Algorithmic Efficiency: Analyze code complexity and execution performance using Big-O notation.

Object-Oriented Programming (OOP): Apply core principles—Encapsulation, Inheritance, Polymorphism, and Abstraction—to system design.

Database & Data Integration: Connect software applications to persistent storage and handle structural data exchanges.
